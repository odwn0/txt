# TXT Fan Streaming Archive

A responsive, unofficial TXT fan archive inspired by streaming-platform interfaces.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## GitHub Pages

Enable Pages in repository settings and deploy from the `main` branch, `/ (root)` folder.

## Content policy

- Uses only verifiable TXT album and track names.
- Uses official YouTube embeds or official-platform search links.
- No paid API or backend is required.
- This is an unofficial fan project with no affiliation to HYBE or TOMORROW X TOGETHER.
